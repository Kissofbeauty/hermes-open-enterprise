# Organization skills

Hermes skills available to every agent: `<category>/<skill-name>/SKILL.md` (frontmatter `name` + `description`).
A skill here wins over a department or personal skill with the same name.
Documents (policies, product facts …) do **not** need a skill — put them in `Policy/`, `Knowledge/`, `KPI/`
or `Core-values/`; the built-in `org-navigator` skill finds them.
